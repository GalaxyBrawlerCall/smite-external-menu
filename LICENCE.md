## 🧩 About

**Smite External Menu** is a curated list of Smite open-source tools:

- **Overlays** — on-screen helpers, layout notes, ability cooldown viewer, map radar
- **Quality-of-Life Helpers** — item catalog, build manager, overlay notes
- **Research Notes** — practice layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

---

## ✨ Features

### ESP
- Cooldown Viewer — track ability timers
- Map Radar — show nearby objectives and jungle timers
- Replay Notes — record and review match runs
- Playback Speed — adjust replay playback for study (0.1x to 5x)

### Wallhack
- Item Catalog — browse items, relics, skins
- Custom Skin Notes — organize god cosmetics
- Ability Range Indicator — improved range visibility

### Aimbot
- Practice Mode Notes — segment study on any god
- Camera Control — manually adjust camera distance
- Input Buffer Notes — chain complex combos in practice
